`@bloxwap/chart` is a financial charting library with no runtime dependencies. It renders into a canvas supplied by your application and keeps data, series, indicators, drawings, and appearance in one typed configuration.

The library is in development. These docs describe the code in this repository. The first npm release is still pending; use the [source installation](/docs/getting-started#install-from-source) to try it today.

## How the pieces fit

The **core** owns the data, scales, and rendering. You provide a canvas or a small document abstraction. It has no dependency on React and does not access the global browser document.

The **UI layer** is an optional import from `@bloxwap/chart/ui`. It adds pointer and touch navigation, drawing controls, a header bar, the settings card, an indicator dialog, context menus, and theme styling. You provide the browser document and the containers where that UI should appear.

The **datafeed** is an optional import from `@bloxwap/chart/datafeed`. It loads history through one function you write, pages older bars in as the user scrolls, and folds live ticks into bars.

The **registries** hold indicator calculations and drawing models. Built-in models work immediately; applications can register their own implementations.

## What is included

- Candlestick, hollow candle, Heikin Ashi, line, area, OHLC bar, and volume histogram series, with an optional volume overlay.
- 20 indicators, including moving averages, Bollinger Bands, VWAP, Ichimoku, Supertrend, MACD, RSI, Stochastic, ADX, and volume, with per-plot styling.
- Drawing tools for lines, patterns, Fibonacci, annotations, measurements, and more.
- Price lines and bar markers for live values such as a mark price or order fills.
- Regular, percent, indexed, and logarithmic price scales, and a bar-indexed or time-continuous time axis.
- A shared configuration for themes, brand presets, labels, crosshair, grid, watermark, and formatters.
- Events for the visible range, crosshair, data loads, and layout, plus snapshots and a bar-close countdown.
- Optional WASM/SIMD calculation kernels with a JavaScript fallback.
- Mock canvas and document implementations for tests.

The package renders supplied data. Market feeds, symbol lookup, exchange connections, and trading actions belong to your application.
