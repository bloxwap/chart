## Install from source

`@bloxwap/chart` is not yet published on npm. For now, build and package the repository using Node.js 24 or newer:

```sh
git clone https://github.com/bloxwap/chart.git
cd chart
npm ci
npm run build
npm pack
```

Install the resulting archive in your application. Version `0.1.0` produces `bloxwap-chart-0.1.0.tgz`:

```sh
cd /path/to/your-app
npm install /path/to/chart/bloxwap-chart-0.1.0.tgz
```

Once the first public release is available, the intended installation command is `npm install @bloxwap/chart`. All examples use this package name, including when installed from the local archive.

## Give the canvas a size

Your application owns layout. Use a wrapper with an explicit height so the canvas has measurable dimensions:

```html
<div id="chart-stage" style="height: 400px; position: relative;">
  <canvas id="chart" style="display: block; width: 100%; height: 100%;"></canvas>
</div>
```

## Create the chart

Run this in a browser module through your application's bundler:

```ts
import { createChart, type Candle } from '@bloxwap/chart';

const canvas = document.querySelector<HTMLCanvasElement>('#chart')!;
const stage = document.querySelector<HTMLElement>('#chart-stage')!;

const data: Candle[] = [
  { time: 1700000000, open: 100, high: 104, low: 98, close: 102, volume: 1200 },
  { time: 1700003600, open: 102, high: 107, low: 101, close: 105, volume: 1800 },
  { time: 1700007200, open: 105, high: 106, low: 100, close: 101, volume: 950 },
];

const chart = createChart({
  container: canvas,
  config: {
    data,
    series: { type: 'candlestick', upColor: '#26a69a', downColor: '#ef5350' },
  },
});

const resize = () => {
  chart.resize(stage.clientWidth, stage.clientHeight, window.devicePixelRatio || 1);
};
const observer = new ResizeObserver(resize);
observer.observe(stage);
resize();

chart.scale.zoomToRange(0, data.length - 1);
await chart.ready;
```

Timestamps are **UNIX seconds**, not milliseconds. Width and height passed to `resize` are **CSS pixels**; the library applies the device pixel ratio to its backing canvas.

The core paints immediately. `chart.ready` resolves after WASM initialization or selection of the JavaScript fallback; you do not need to wait before calling other methods.

## Add interaction

The core does not attach pointer listeners. Add the [drawing toolbar](/docs/guides/toolbar-settings) for drag, wheel, crosshair, and drawing interactions, or wire your own controls to the [scale API](/docs/api/scale).

## Update and clean up

```ts
chart.appendData({ time: 1700010800, open: 101, high: 108, low: 100, close: 107 });
chart.updateConfig({ grid: { visible: false } });

// When your view is removed:
observer.disconnect();
chart.destroy();
```

Destroy any toolbar and settings handles before destroying the chart. Your application must also cancel its own timers, network subscriptions, and observers.
